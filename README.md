# asmaa 🎂

صفحة عيد ميلاد لأسماء — صفحة واحدة، بدون build ولا مكتبات.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 4173
```

## الملفات

| الملف | إيه فيه |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم والأنيميشن |
| `script.js` | كل المحتوى في بلوك `CONFIG` فوق + المنطق |
| `images/` | الصور (`hero.jpeg` + `photo1..11.jpeg`) |
| `song.mp3` | مزيكا الخلفية |

## تعديل المحتوى

كل الكلام والتواريخ والصور في بلوك `CONFIG` في أول `script.js` — التواريخ، الجُمَل، كابشنات الصور، الحكاية، أسباب الحب، والرسالة.

## المكوّنات

شاشة تورتة بشمعة تتطفي بالدوس أو بالنفخ في المايك · عدّاد حيّ بيعدّ تنازلي لعيد الميلاد وبيقلب لعدّ طالع بعد نص الليل · معرض صور بلايت بوكس · خط زمني · كروت بتتقلب · رسالة بتتكتب حرف حرف · صندوق هدية · كونفيتي ومزيكا.
